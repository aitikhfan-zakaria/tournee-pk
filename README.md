# Tournée PK

Application web pour iPhone : affiche en direct le PK ferroviaire (format `02+520`) sur la ligne Benguérir – Safi, permet de noter les anomalies de voie pendant la tournée et produit un compte rendu (Word, texte ou XML) en fin de tournée.

- Le parcours (points KM 1 à KM 91) est intégré dans `index.html`.
- Les anomalies et comptes rendus restent uniquement dans le téléphone.
- Ouvrir l'adresse GitHub Pages dans Safari, puis Partager › Sur l'écran d'accueil.
